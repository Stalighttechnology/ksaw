# Skill Registration Form

Create a fully responsive registration form page closely matching this reference:

https://skillmission.karnataka.gov.in/app/registration

Recreate the same UI, layout, styling, form sections, and all visible form fields from the reference. Do not omit or simplify any fields.

Match:

Header/logo

Form layout and sections

Labels, placeholders, dropdowns, radio buttons, checkboxes and date fields

Colors, typography, spacing, borders and buttons

Required-field indicators and validation

Desktop, tablet and mobile responsiveness

The page must have no horizontal scrolling and should look polished and production-ready on all screen sizes.

Use React + TypeScript with clean, reusable components and proper form validation.

Important: First inspect the reference URL carefully and use it as the source of truth. Do not create a generic registration form or add unnecessary design elements. Make the result visually as close to the reference as possible.
